App walkthroughs

Field Assessment (walk) — Zone of operation → pin each Gold Code point → photo → score 0–5 against the standard legend → BOQ → report. Score only what you can evidence; a 5 means compliant with the written standard, not "looks fine".
Plant Sample Capture — Pin → Gold Code section → mark every control ✓/✗/N/A → threat indicators → 2 photos (wide + close with tag) → Material Class → read the routing card → mass, container, seal number, seal confirmed, witness → sign. The seal and the signature are zero-defect items.
Incident Capture — Class and severity → occurrence window from/to (not the discovery time) → section → barriers Held / Failed / Bypassed / Absent → key barrier → facts only, persons by role → plant conditions → link samples → recovered material sealed → sign. You do not pick a hypothesis.
